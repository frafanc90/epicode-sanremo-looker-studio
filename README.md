# Sanremo 1951-2023: il verdetto di allora regge oggi?

Esercitazione finale del modulo - Google Looker Studio (Epicode Data Analytics & AI Bootcamp).

## Tema dell'analisi
Il piazzamento ottenuto al festival di Sanremo predice la popolarità attuale su Spotify della canzone in gara? Analisi su 1663 canzoni, 73 edizioni (1951-2023).

## Report interattivo
👉 [Apri il report su Looker Studio](https://datastudio.google.com/reporting/ac0207f2-f9f3-42ce-b9bf-8caea4f581e6)

## Contenuto del repository
- `Report Sanremo - classifica.csv`: dataset pulito e integrato (classifica + catalogo Spotify + dati festival)
- `Report_Sanremo_1951-2023.pdf`: esportazione statica del report (senza interattività dei filtri)

## Metodologia
Dati forniti in tre tabelle separate (classifica, catalogo Spotify, dati festival), integrati tramite Google Sheets con pulizia del campo posizione/stato e join su Canzone/Anno. Dettagli del processo nel report stesso.
